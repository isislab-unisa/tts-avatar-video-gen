# Dubme

Cloud-Native Web Platform for 3D Avatar Multimedia Authoring.
A full-stack platform built with Next.js (frontend) and GoFiber (backend) designed for creating voice and video content using external Text-to-Speech (TTS) and Lip Syncing APIs, applied to 3D avatars.
Features include modern authentication (email, Google, GitHub), internationalization via next-intl, storage management with MinIO, and data persistence using MongoDB.
The UI is built using components from shadcn/ui and Aceternity.
